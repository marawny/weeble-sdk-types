# Weeble SDK

**Build the bot. Weeble runs it.**

Build and deploy Discord bots with TypeScript without managing servers or
infrastructure. Weeble provides the editor, runtime, deployments, and logs so
you can focus on the bot itself.

This repository contains the public type definitions for the Discord and
runtime APIs available inside Weeble.

Browse the [SDK reference](https://weeble.works/docs/reference/discord/) or read
the [getting-started guides](https://weeble.works/docs/).

Start building at [weeble.works](https://weeble.works).
